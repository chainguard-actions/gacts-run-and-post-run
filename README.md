# gacts/run-and-post-run

A simple GitHub action that allows you to execute commands on place and in post-run, once a workflow job has ended

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/gacts/run-and-post-run](https://github.com/gacts/run-and-post-run).
